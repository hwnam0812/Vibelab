PHASE 6 · LEARN VIBE CODING

            
바이브 코딩 배우기

          

          

            
1. 아이디어 설명
무엇을 만들고 싶은지 목적, 사용자, 핵심 기능을 자연어로 설명합니다.
학생 공부 시간 관리 앱을 만들어줘.

            
2. 앱 구성
AI가 화면, 사용자 흐름, 데이터 구조를 설계합니다.

            
3. 기능 구체화
각 기능의 입력/출력/예외/상태를 정의합니다.

            
4. 코드 생성
AI가 기존 프로젝트를 분석하고 필요한 파일을 수정합니다.

            
5. 실행 및 테스트
테스트 결과를 확인하고 오류를 수정합니다.

            
6. 좋은 프롬프트
대상, 화면, 기능, 제약 조건을 구체적으로 적을수록 좋습니다.
